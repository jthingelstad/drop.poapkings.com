# summaries/

Historical weekly digests from the retired Manager model, one per ISO week
(`YYYY-Www.md`). This is the durable "how the project evolved" record — what shipped, what's in
flight, what slipped through the cracks, how each role performed, and any `meta` proposals filed.

The retired model's local `../notes/` directory may still exist as ignored historical
scratch, but current objective runs use compact automation memory instead. These
summaries remain committed history. See `../WORKFLOW.md`.
